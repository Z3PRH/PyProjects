# Unit Converter

Convert Your Input btw Desire Unit Based on Set Categories

# Current Unit Conversion 
- Temperature (Celsius to Fahrenheit)
- Distance (Km to Miles)
- Weight (Kg to Pounds)

Unit Conversion Works Both SideWays

> **Formulas**
> 
> - Celsius to Fahrenheit: `F = C × 9/5 + 32`
> - Fahrenheit to Celsius: `C = (F - 32) × 5/9`
> - Kilometers to Miles: `mi = km × 0.62137`
> - Miles to Kilometers: `km = mi / 0.62137`
> - Kilograms to Pounds: `lb = kg × 2.20462`
> - Pounds to Kilograms: `kg = lb / 2.20462`

# How to Use
1. Run `unit_converter.py`.
2. Choose one category: `Temperature`, `Distance`, or `Weight`.
3. Enter the numeric value to convert.
4. Choose the conversion direction:
   - Temperature: `Celsius` or `Fahrenheit`
   - Distance: `Km` or `Miles`
   - Weight: `Kg` or `Pounds`
5. After the result, enter `Yes` to convert again or `No` to exit.

# Example
- Input: Category = `Temperature`, Value = `25`, Direction = `Celsius`
- Output: Converts 25°C to 77°F

# Notes
- Type the category and conversion direction exactly as shown.
- The program accepts numeric values for conversion.
- The result displays both the original and converted units.
