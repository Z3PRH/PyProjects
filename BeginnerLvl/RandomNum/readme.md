Number Guessing Game
Guess the secret number....That's it :D
How it works
Computer picks a number between 1-100. You guess. It tells you if you're too high or too low. Keep guessing until you get it right. (Or give up. No judgment.)
Run it
bashpython randomnum.py
Features

Random number (1-100)
Hints (too high/too low)
Attempt counter
Play again option
Laugh at yourself when it takes 20 attempts

Patience (optional but recommended)


How many attempts does it take you? 👀
